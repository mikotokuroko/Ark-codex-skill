# Included pet assets

Releases bundle only **史尔特尔—超然序曲**, with 642 transparent frames across
idle (Relax), interact, move, sit, sleep and Special at 20 fps.

Source: [PRTS 史尔特尔](https://prts.wiki/w/史尔特尔).
[Model metadata](https://torappu.prts.wiki/assets/char_spine/char_350_surtr/meta.json).

Other character folders are ignored by Git and excluded from both application
builds. Generated user packs stay in the app’s user-data directory. Raw models,
export tools and user settings are not bundled in the applications.

Game artwork and character assets belong to their respective rights holders.
The repository license does not license the underlying artwork.
